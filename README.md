# 나에게 맞는 에코업 찾기

관심사에 따라 에코업 마이크로디그리 분야를 추천하는 정적 웹페이지입니다. 학년·전공 계열·과정 인지도를 물은 뒤, 관심사별 질문을 따라 12개 분야 중 하나를 보여줍니다. 응답은 브라우저에서만 처리하며 서버로 전송하지 않습니다.

## 실행

`index.html`을 브라우저에서 열거나 정적 파일 서버로 이 디렉터리를 제공하면 됩니다. 별도의 빌드나 패키지 설치가 필요하지 않습니다.

## GitHub Pages 배포

저장소의 기본 브랜치에 파일을 올린 뒤 **Settings → Pages → Build and deployment → Deploy from a branch**에서 기본 브랜치와 `/ (root)`를 선택합니다. 공개 주소는 `https://사용자명.github.io/저장소명/`입니다.

결과는 관심사 기반 탐색용 추천입니다. 과정명과 실제 개설 여부 및 신청 조건은 학교의 최신 공식 안내로 검토해야 합니다.
